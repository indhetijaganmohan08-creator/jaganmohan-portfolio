# Jagan Mohan Indheti — Portfolio

A professional React + Vite portfolio for a Machine Learning Engineer / AI Software Developer.

## Requirements

- Node.js 20+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Personalize before deployment

Edit:

`src/data/portfolioData.js`

Update:
- email
- education
- project links
- project descriptions
- skills
- experience

Add your resume as:

`public/resume.pdf`

If you want to use your professional photo, replace the initials placeholder in `src/App.jsx` with an image from `/profile.jpg`.

## Deployment

This is a standard Vite SPA and can be deployed to Vercel, Netlify, GitHub Pages, AWS, Hostinger or any static hosting service that supports SPA routing.
